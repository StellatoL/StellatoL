### 📌 关于我

- 🎓 **专业方向**：电子信息工程 · 嵌入式异构计算 / 机器人感知与导航
- 🔭 **正在推进**：基于 ROS 2 + Nav2 的自主移动底盘控制，以及边缘端视觉算法（NPU）部署
- 🛠️ **技术关注**：软硬件协同设计、低延迟数据链路（PCIe DMA / 共享内存）、深度学习模型量化与加速
- 🧩 **工程习惯**：从 STM32 裸机固件一路贯通到 ARM Linux 应用、上位机工具链与 ROS 2 上层算法
- 📝 **技术沉淀**：持续整理调试记录、协议设计与论文/源码阅读笔记
